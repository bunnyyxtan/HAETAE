Enforcement Flow
fail closed at every step
principal verified via Dojang → license minted to the agent → policy set: cap and venues → agent trades through the gate → unlicensed or out of policy reverts → revocation lands in one block → permanent public verdict page
The default is refusal. A missing license, an expired license, a spent cap, or an unknown venue ends the same way: the trade reverts.
Identity
two lanes, one interface
Lane 1 · DojangScroll

Reads Upbit Korea verification attestations. This is the mainnet rail.

Lane 2 · GIWA EAS predeploy

Attestations on GIWA’s EAS predeploy. Live on testnet with the self-serve verification desk.

Both lanes sit behind one interface, IVerifiedAddress. Switching lanes is constructor arguments, not new code.
